# 🎀 치이카와 굿즈 가챠

치이카와 공식 굿즈를 캡슐 가챠로 뽑아 도감에 모으고, 마이룸에 자유롭게 꾸미는 팬 미니게임입니다.

- **가챠**: 1회 / 10연차 뽑기, SR·SSR 전용 연출, 50회 SSR 천장
- **도감**: 등급 · 캐릭터 · 종류 · 컬렉션 필터, 굿즈 확대 보기
- **마이룸**: 뽑은 굿즈를 방에 드래그해서 배치, 벽지 5종
- 다크/라이트 모드, 볼륨 조절, 모바일 · 태블릿 · 데스크톱 반응형

진행 상황(코인, 도감, 마이룸)은 각자의 브라우저에만 저장됩니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 게임 전체 (GitHub Pages가 이 파일을 보여줍니다) |
| `serve.ps1` | PC에서 미리보기: `powershell -File serve.ps1` 후 http://localhost:5173 |
| `fetch-images.ps1` | claude.ai 게시용 이미지 사본을 `img/`에 받기 (저장소에는 올리지 않음) |
| `build-publish.ps1` | claude.ai 게시용 페이지를 `publish/`에 만들기 |

## 저작권

「치이카와(ちいかわ)」의 모든 캐릭터, 굿즈 디자인, 상품 이미지의 저작권·상표권은 원작자 **나가노(ナガノ)** 와 **ⓒnagano / chiikawa committee** 에 있습니다.

이 프로젝트는 공식과 관계없는 비영리 취미 팬 제작물이며, 원작자·제작위원회·판매처의 승인이나 후원을 받지 않았습니다. 광고, 판매, 후원 요청 등 어떠한 영리 목적도 없습니다.

굿즈 이미지는 이 저장소에 포함되어 있지 않으며, 공식 온라인 상점 [ちいかわマーケット](https://chiikawamarket.jp)의 상품 이미지 주소에서 직접 불러옵니다. 권리자의 요청이 있으면 즉시 내리겠습니다.
